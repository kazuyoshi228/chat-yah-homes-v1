## RAG化できる知識

### 1. エアコンリモコンの使い方（remotecontrol.pdf・日英対訳の完全な操作ガイド）
「How to operate」— リモコンの図解つき:
- 画面表示: 運転中=Operating／自動=Auto／標準=Standard／風量自動=Auto Fan Speed
- モード: 冷房=Cooling／暖房=Heating／除湿=Dry／送風=Fan only
- 上部ボタン: 快適自動=Comfort Auto／運転・停止=Power On/Off／風量=Fan Speed／温度=Temperature
- 下部ボタン: 運転切換=Mode Selection／上下風向=Up/Down Airflow Direction／左右風向=Left/Right Airflow Direction／切タイマー=Off Timer
→ RAG文書「エアコンの使い方」として6言語化可能（リモコンは日本語表記なので対訳が価値）

### 2. 避難経路（1F/2F/3F の避難経路図サイン）
- 各階に避難経路図（Emergency Exits）を掲示
- 1F: 廊下を通って建物出入口（Exits）へ。避難口サイン（Emergency Exit）表示あり
- 図面ベースのため文言化は限定的 →「避難経路図が各階に掲示されている・非常時は掲示の経路で1F出入口へ」という案内＋緊急連絡先のRAGに
- ※2F/3F の図も同様（階段で1Fへ降りる動線）

### 3. Wi-Fi（記載内容はRAG化しない）
- お部屋にWi-Fiのアクリルサイン（SSID 2.4GHz/5GHz・WPAパスワード記載）を掲示
- → RAGには「Wi-Fi情報はお部屋のサインに掲示。見当たらない場合は予約経路のメッセージで確認」とだけ書く

### 4. 表札・チェックイン導線（nyuko サイン）
- 入居（チェックイン）案内サインとドアサインが存在（表札と同内容＝施設名・住所・緊急連絡先）
- 具体的なチェックイン手順（鍵の受け渡し・暗証番号）はこの資料には無い → ヒアリング待ち
